# Заливайко by Kavalets

Заливка записів OBS на YouTube для Windows: черга з підтвердженням, обрізка інтро, 2K/4K, превью, списки відтворення, публікація за розкладом — усе з панелі.

Розробник: **Kavalets** · Telegram: https://t.me/dmytrokavalets

## Встановлення

1. Завантажте `Заливайко-by-Kavalets-v….zip` з останнього релізу: **[Releases](../../releases/latest)**.
2. Розпакуйте в постійну папку (наприклад `D:\Заливайко`) і запустіть **Заливайко.exe** — далі все підкаже панель. Повна інструкція — `ІНСТРУКЦІЯ.html` в архіві.

## Оновлення

- **Автоматично:** Заливайко сам перевіряє цей репозиторій і показує «Доступна нова версія → Оновити».
- **Зі старої версії (без автооновлення):** розпакуйте новий архів будь-куди й запустіть з нього `Заливайко.exe` → «Оновити».
- **Через Claude / термінал:** `node app\tools\update.mjs` з розпакованої папки.

Вхід у Google, канали й налаштування при оновленні не змінюються.

Кожен реліз має `.sha256` — оновлювач перевіряє ним завантажений архів.
